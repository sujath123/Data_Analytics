# Enterprise Data Reconciliation & Revenue Analytics

This project builds an end-to-end data reconciliation and analytics workflow for enterprise revenue reporting. It combines raw transaction logs, active customer data, and daily exchange-rate information to generate a trusted revenue dataset and a Power BI executive dashboard.

The solution is designed to answer key business questions such as:

- What is the real total revenue in USD after reconciliation?
- Which customers contribute the most to revenue?
- Which transactions are valid, and which should be excluded due to data quality issues?
- How does monthly revenue trend over time?
- What is the current operational health of the data pipeline?

---

## Project overview

This repository contains:

- A Python-based data processing workflow for cleaning and reconciling raw event logs
- A Power BI project with executive, customer, and reconciliation dashboards
- Aggregated CSV outputs used as the reporting layer
- A source notebook documenting the full data engineering process

The result is a reproducible pipeline that transforms messy operational data into business-ready reporting tables.

---

## Business objective

The project focuses on reconciling operational transaction records with the latest active user data and daily EUR-to-USD exchange-rate values. In practice, this means:

1. Filtering out noisy or failed server log entries
2. Retaining only valid transactions from active users
3. Forward-filling missing exchange-rate values where necessary
4. Converting euro-based values into USD revenue
5. Producing monthly and customer-level aggregates for decision-making

This creates a reliable basis for financial reporting and executive KPI monitoring.

## Dataset and data flow

### Source inputs

The project uses these key inputs:

- server_logs.txt: raw operational log file containing transaction events
- daily_exchange_rates.csv: daily EUR-to-USD conversion data
- enterprise user data: latest active customer records from a SQL/warehouse source
- reconciliation outputs: transformed data tables generated by the pipeline

### Transformation steps

The analytics flow includes:

1. Extracting the latest active users using SQL window functions
2. Reading server log lines and filtering out ERROR entries
3. Parsing JSON-like payloads using regex to recover structured transaction details
4. Joining transaction records with exchange-rate data on the transaction date
5. Forward-filling missing exchange rates
6. Merging with active-user records to keep only valid customer transactions
7. Calculating USD revenue using:
   - USD_Revenue = Euro_Value × EUR_to_USD
8. Aggregating results into:
   - monthly revenue
   - top customer revenue summary
   - reconciled transaction fact table

The dashboard is implemented as a Power BI project and is designed for executive review. It includes:

- KPI cards for revenue, transactions, active users, and error logs

- A customer revenue bar chart highlighting the top five customers

This dashboard is intended to provide an operational and financial snapshot for leadership and cross-functional stakeholders.

## How to use this project

### Option 1: Open the Power BI report

1. Open the project file named Enterprise_Reconciliation.pbip in Power BI Desktop.
2. Refresh the dataset if required.
3. Explore the executive, customer, and reconciliation pages.

### Option 2: Recreate the transformation steps

1. Open the notebook in Enterprise_Data_Reconciliation/source/Enterprise_Reconciliation_Completed.ipynb.
2. Run the cells in order.
3. Review the generated CSV outputs in Enterprise_Data_Reconciliation/data/.

### Option 3: Use the prepared data tables

If you only need the reporting outputs, use the CSV files already generated in the data folder and connect them to Power BI or Excel for analysis.

This project is a data reconciliation and reporting solution rather than a traditional application or web app. It is focused on extracting value from raw enterprise operational data and building an auditable analytics foundation for business decisions.
